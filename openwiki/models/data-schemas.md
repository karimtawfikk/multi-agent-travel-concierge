# Pydantic Models & Data Schemas

All structured data across the API endpoints and CrewAI agent tasks is strictly validated using **Pydantic v2** models defined in [`src/models.py`](file:///c:/Users/kelsahn/OneDrive%20-%20Capgemini/Desktop/multi-agent-travel-concierge/src/models.py) and [`src/server.py`](file:///c:/Users/kelsahn/OneDrive%20-%20Capgemini/Desktop/multi-agent-travel-concierge/src/server.py).

## Schema Hierarchy Overview

```
TripPlanRequest (FastAPI Endpoint Input)
       │
       ▼
TripSpatialBlueprint (Lead Architect Intermediate Output)
   ├── DaySpatialAnchor (District zoning per day)
       │
       ▼
CompleteTripItinerary (Master Synthesis Output)
   ├── WeatherAdvisory (Open-Meteo forecast & packing advice)
   ├── FlightRecommendation
   │      └── FlightOption
   │             └── FlightLeg (Outbound & Inbound times/stops)
   ├── List[StayRecommendation] (Boutique lodging & neighborhoods)
   ├── List[DayPlan]
   │      ├── List[ActivityItem] (12-hour AM/PM timed activities)
   │      └── List[DiningItem] (Breakfast, Lunch, Dinner, Cafe)
   └── BudgetSummary (Itemized category breakdown & currency audit)
```

## Core Model Specifications

### 1. `TripPlanRequest` ([`src/server.py:L52-L69`](file:///c:/Users/kelsahn/OneDrive%20-%20Capgemini/Desktop/multi-agent-travel-concierge/src/server.py#L52-L69))
Incoming request payload for `/api/plan-trip-stream` and `/api/plan-trip`:
- `destination`: Target city/country (required).
- `duration_days`: Number of trip days (default 3, clamped between 1 and 14).
- `travel_style`: Travel persona (e.g. "Cultural & Foodie").
- `interests`: Comma-separated sights or themes.
- `budget`: Target expenditure amount string (e.g. "1200").
- `currency`: User's base currency code (default "USD").
- `origin`, `departure_date`, `return_date`: Flight parameters.

### 2. `TripSpatialBlueprint` ([`src/models.py:L12-L17`](file:///c:/Users/kelsahn/OneDrive%20-%20Capgemini/Desktop/multi-agent-travel-concierge/src/models.py#L12-L17))
Generated by the Lead Trip Architect to anchor downstream scout specialists:
- `destination`: Destination city/region.
- `duration_days`: Usable activity days calculated from flight schedules.
- `recommended_stay_neighborhoods`: Top 1-2 central districts to anchor lodging.
- `daily_anchors`: List of [`DaySpatialAnchor`](file:///c:/Users/kelsahn/OneDrive%20-%20Capgemini/Desktop/multi-agent-travel-concierge/src/models.py#L5-L10) assigning `theme`, `district_focus`, and `strategic_rationale` per day.

### 3. Day Schedule: `DayPlan`, `ActivityItem`, and `DiningItem` ([`src/models.py:L19-L47`](file:///c:/Users/kelsahn/OneDrive%20-%20Capgemini/Desktop/multi-agent-travel-concierge/src/models.py#L19-L47))
- **`ActivityItem`**: Enforces time windows formatted in 12-hour AM/PM (e.g. `'Morning (09:30 AM - 12:00 PM)'`), `title`, `description`, `location_name`, `cost_estimate`, and `booking_tips`.
- **`DiningItem`**: Specifies `meal_type` (`'Breakfast'`, `'Lunch'`, `'Dinner'`, or `'Snack/Cafe'`), `name`, `cuisine`, `price_level` (`'$'`, `'$$'`, `'$$$'`), and `must_try_dish`.
- **`DayPlan`**: Ties together activities, dining, and daily `transit_notes` for each calendar day.

### 4. `BudgetSummary` ([`src/models.py:L57-L66`](file:///c:/Users/kelsahn/OneDrive%20-%20Capgemini/Desktop/multi-agent-travel-concierge/src/models.py#L57-L66))
Financial audit produced by the Budget Analyst:
- `lodging_total`, `food_total`, `activities_total`, `transit_total`, `grand_total`: Dual-currency strings showing local destination currency and approximate user currency.
- `currency`: Primary destination fiat currency code (e.g. "JPY", "EUR", "EGP").
- `within_budget`: Boolean flag confirming whether the total trip cost is within the user's budget ceiling.
- `savings_tips`: List of practical localized cost-reduction recommendations.

### 5. `CompleteTripItinerary` ([`src/models.py:L106-L118`](file:///c:/Users/kelsahn/OneDrive%20-%20Capgemini/Desktop/multi-agent-travel-concierge/src/models.py#L106-L118))
Final synthesized contract expected by both the CLI and frontend UI:
- Enforces presence of weather advisory, optional flights recommendation, lodging stays, day plans, budget summary, `airport_transfer_guide`, and `general_transit_tips`.
